1.
```php
$nums='';
for ($i = 2; $i <= 200; $i++) {
    $isNumber = true;
    for ($j = 2; $j * $j <= $i; $j++) {
        if ($i % $j === 0) {
            $isNumber = false;
            break;
        }
    }
    if ($isNumber) {
        $nums.= $i.',';
    }
}
echo rtrim($nums,',');
```

```php
$nums='';
```
