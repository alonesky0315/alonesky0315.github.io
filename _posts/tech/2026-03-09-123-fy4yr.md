#### 安装openclaw

一、 安装
1. Windows (PowerShell)一键安装
```
iwr -useb https://openclaw.ai/install.ps1 | iex
```
2. 手动全局安装   
先安装nodejs，再手动安装openclaw
```
// 重装最新版
npm install -g openclaw@latest --force
// 补上缺的“日历/Carbon”包（关键）
npm install -g @buape/carbon
// 再补其他常见缺包（一次到位）
npm install -g @larksuiteoapi/node-sdk @slack/web-api grammy
```
pnpm安装
```
// pnpm add -g openclaw@latest
```

二、 验证安装

```
#查看版本
openclaw --version
```

三、 运行新手引导向导（并安装服务）
```
openclaw onboard --install-daemon
```

四、 OpenClaw常用命令
```
#初始化配置目录
openclaw setup
#配置向导（首次安装）
openclaw onboard --install-daemon
#初始化向导
openclaw onboard
#重置配置
openclaw setup --reset config
#重新进入配置向导
openclaw configure
#查看/修改配置
openclaw config
#管理技能
openclaw skills
#查看帮助
openclaw --help
#启动可省略start
#openclaw gateway
openclaw gateway start
#停止
openclaw gateway stop
#重启
openclaw gateway restart
#查看状态
openclaw gateway status
#前台运行打印调试
openclaw gateway --port 18789 --verbose
#前台运行（挂终端，用于调试）
openclaw gateway run
#打开网页控制台
openclaw dashboard
#诊断问题（自动修复）
openclaw doctor
#使用其他端口
openclaw gateway --port 18790
#检查版本
openclaw --version
#安装网关
openclaw gateway install
#检查并更新 CLI
openclaw update

#快速验证
openclaw status
openclaw health
openclaw security audit --deep

#插件管理核心命令
#安装插件	
openclaw plugins install 插件名
#查看已安装插件	
openclaw plugins list
#卸载插件	
openclaw plugins uninstall 插件名
#更新插件	
openclaw plugins update 插件名
```
