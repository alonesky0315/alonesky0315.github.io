#### 打造 Web 在线聊天室
1. Node.js 安装
```
curl -sL https://rpm.nodesource.com/setup_14.x | sudo bash - && sudo yum clean all && sudo yum makecache fast && sudo yum install -y gcc-c++ make && sudo yum install -y nodejs
```
2. 创建目录
   ```
   mkdir /www
   ```
3. 拉取 socket demo
```
wget https://codeload.github.com/socketio/chat-example/zip/refs/heads/master && unzip master && mv chat-example-master/* /www/
```
4. 安装 Express
```
cd www && npm install express --save
```
5. 搭建 Socket.io
```
npm install --save socket.io
```
6. 关闭 https 强制效验
```
npm config set strict-ssl false
```
7. 运行 demo
```
node index.js
```
